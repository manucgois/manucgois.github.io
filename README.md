# Portfólio — Manuela Góis

Site pessoal feito com HTML, CSS e JavaScript puro, publicado com GitHub Pages.

🔗 https://manucgois.github.io

## Estrutura
- `index.html` — conteúdo das seções (Início, Sobre, Projetos, Currículo, Contato)
- `style.css` — visual (cores no topo, em `:root`)
- `script.js` — menu do celular e animações ao rolar
- `assets/` — foto, prints dos projetos e currículo em PDF
